## Suggestions (not applied)
1. **Settle precedence first, by topic rather than all at once.** Both sets are carefully written. A short merge session, topic by topic in the table above, would give one DECISIONS log that both docs follow.
2. **Watch the energy vs gather-time choice.** It shapes everything else. Energy gives D-084's two short check-ins a day. Long gather times and a 2.5-month nonstop XP target reward hours online, which favours bots unless the server checks timing.
3. **Holder bonuses that scale with imp count** risk pay-to-win against pillar D-085, especially if mint tokens can be traded off-game. Keep them cosmetic, or cap them.
4. Create a **`main`** branch in club-impz and make it the default, so the "commit to main" workflow and backup tags work as written.
