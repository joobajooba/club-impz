# docs

Markdown documents for the project: design docs, specs, plans and notes. Start here if you are looking for a doc.

**Two sets of design docs live here.** The IMPLINGZ set came from the COLLAB_IMPZ repo on 2026-10-30: it treats [DECISIONS.md](DECISIONS.md) as the source of truth. J00BA's Club Impz set treats [game_direction.md](game_direction.md) as the source of truth. Which one wins where they disagree is an **Open question** for the two collaborators. Until it is answered, neither set changes the other.
