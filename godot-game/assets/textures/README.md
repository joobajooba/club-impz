# godot-game/assets/textures

Textures and materials used by the game.

| Folder | What goes here |
| --- | --- |
| `trees/`, `foliage/` | Textures for the Blockbench models, same name as the model |
| `terrain/` | Tiling 128 × 128 ground textures for the terrain (`docs/terrain_textures.md`), generated by `tools/generate_terrain_textures.py` |
